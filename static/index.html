YouTube sign-in

If downloads fail with “confirm you're not a bot”, the app can use your YouTube login. It's only ever sent to YouTube. A spare Google account is safest, because YouTube can flag accounts that download a lot.

  1. In Chrome (or any browser), install the Get cookies.txt LOCALLY extension.
  2. Open youtube.com and make sure you're signed in.
  3. Click the extension, then Export, and upload that file here.
